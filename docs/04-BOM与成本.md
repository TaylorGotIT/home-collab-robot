# 04 · BOM 与成本

> **口径**：人民币含税价、2026 年国内市场中位估算、不含研发摊销与物流关税。所有单价都是**谈判起点**而非成交价，量产列是"1000 台/年、双源、自研臂"条件下的目标价。
> **唯一数据源**：[`data/bom.csv`](../data/bom.csv)。本文件中的表格由 `python scripts/calc_cost.py --bom-md` 生成，CI 会校验两者一致。

## 一、三档成本汇总

| 版本 | BOM 小计 | 备件损耗 | 单台成本 | 折合万元 |
| --- | ---: | ---: | ---: | ---: |
| 原型（A 样） | 97,730 | 7,818（8%） | **105,548** | **10.6** |
| 小批（100 台） | 61,770 | 3,088（5%） | **64,858** | **6.5** |
| 量产（1000 台/年） | 39,950 | 1,198（3%） | **41,148** | **4.1** |

从原型到量产，单台成本下降 **61%**。这个降幅不是靠"砍配置"，而是靠三件事：机械臂自研、结构件模具化、电子料规模采购。

## 三、分系统成本占比

| 分系统 | 原型小计 | 占比 | 量产小计 | 占比 | 趋势 |
| --- | ---: | ---: | ---: | ---: | --- |
| 机械臂 | 26,000 | 26.6% | 7,500 | 18.8% | 自研后大幅下降 |
| 环境感知 | 10,050 | 10.3% | 4,680 | 11.7% | 占比反升，是价值核心 |
| 爬楼机构 | 9,500 | 9.7% | 3,800 | 9.5% | 稳定，难降 |
| 电源 | 9,400 | 9.6% | 4,800 | 12.0% | 电池降价慢 |
| 计算平台 | 8,400 | 8.6% | 5,500 | 13.8% | 占比升高，算力不能省 |
| 移动底盘 | 7,500 | 7.7% | 3,280 | 8.2% | 规模效应 |
| 制造 | 6,000 | 6.1% | 2,500 | 6.3% | 工装摊薄 |
| 结构 | 3,500 | 3.6% | 700 | 1.8% | 模具化收益最大 |
| 末端执行器 | 3,200 | 3.3% | 1,100 | 2.8% | |
| 升降机构 | 2,800 | 2.9% | 1,200 | 3.0% | |
| 视频 | 2,500 | 2.6% | 1,200 | 3.0% | |
| 定位 | 2,200 | 2.3% | 900 | 2.3% | |
| 电气 | 2,000 | 2.0% | 700 | 1.8% | |
| 安全 | 1,800 | 1.8% | 800 | 2.0% | **不建议压缩** |
| 交互 | 1,500 | 1.5% | 750 | 1.9% | |
| 通信 | 1,380 | 1.4% | 540 | 1.4% | |
| **合计** | **97,730** | 100% | **39,950** | 100% | |

**三个反直觉的结论**：

1. **机械臂占原型的 1/4**，它是"能不能干活"的分水岭，也是降本的最大杠杆。自研一次投入约 300 万，1000 台摊薄 3000 元/台，值得。
2. **安全模块只占 1.8%，但它是保险与认证的入场券**。任何"省掉急停/抱闸"的提议都应该被直接否掉。
3. **感知与算力的占比在量产阶段反而上升**——因为便宜的部分都降完了，剩下的降价空间在"更有价值的芯片"上。这意味着量产版本不能靠"减配雷达"降价。

## 六、供应链策略

| 策略 | 具体做法 |
| --- | --- |
| 自研比例 55% | 结构、电控、算法、云平台自研；臂/雷达/电机/电池外购 |
| 关键件双源 | 雷达、深度相机、电机、电池各 2 家，B 样起同步验证 |
| 长交期管理 | 雷达 8–12 周、臂 6–10 周 → 安全库存 8 周，B 样起提前 3 个月下单 |
| 单一供应商风险 | 行星减速机、谐波减速器属"卡脖子"件，优先国产替代验证 |
| 备件体系 | 按出货量 5% 备关键件（臂关节、雷达、电池），支撑 48h 换机 |
