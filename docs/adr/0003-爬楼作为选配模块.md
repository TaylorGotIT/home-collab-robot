# ADR-0003 · 爬楼做成"可插拔选配模块"

- **状态**：已接受
- **日期**：2026-11
- **决策人**：项目组

## 背景

爬楼是需求方明确要求的（"可上下楼梯"），但它是全项目可靠性最差、迭代最慢、风险最高的一环：

- 国内老楼踏步高度 150–180mm 不统一，转角平台窄（部分 <1.1m）。
- 静态稳定角约 26.6°（质心 0.55m、轮距 0.55m），30° 坡道已接近极限。
- 单层耗时 3–6 分钟，一旦打滑或失步，后果是整机摔落。
- 结构迭代周期长（开模/加工/装配各 2–4 周），返工即季度级延期。

若把爬楼作为 V1.0 的必交付项，它会把整个项目拖到 30 个月以上。

## 决策

**爬楼作为独立可插拔模块（SKU 选配）**：

- 机械：爬楼模块通过 4 个快锁点 + 1 个电气接口与底盘连接，30 分钟内可拆装。
- 软件：检测到模块在位才加载爬楼状态机；不在位时禁入楼梯区域（地理围栏）。
- 商务：V1.0 标准版不含爬楼（降价 3,800 元），爬楼版单独定价、单独免责、单独培训。
- 节奏：V1.0（M26）交付标准版；爬楼版在 M28 交付，不阻塞首发。

## 代价

1. 快锁结构增加重量约 1.2kg 与成本约 400 元（标准版也要背这个接口）。
2. 两套 SKU 意味着两套认证、两套说明书、两套售后培训。
3. 销售需要判断"这栋楼能不能上"，增加了售前工作量（用"楼栋适配清单"缓解）。

## 替代方案

| 方案 | 为什么没选 |
| --- | --- |
| 爬楼作为 V1.0 必交付 | 关键路径风险过高，一旦延期整个项目停摆 |
| 完全不做爬楼 | 丢失"能上楼看老人"的核心卖点，竞品差异化不足 |
| 换电梯方案（云呼梯） | 依赖物业改造（单栋 3,000–8,000 元），不可控 |

## 影响

- 排期：V1.0 不再被爬楼阻塞，关键路径从"爬楼"变为"遥操作 + 认证"。
- 成本：标准版 BOM 降低 3,800 元（量产口径）。
- 风险：R-01 从"项目级风险"降为"模块级风险"，可独立迭代。
