### 三个购买要点

1. **底盘是全项目性价比核心。** 二手电动轮椅自带减速电机、电磁刹车、100kg 承载和电池，1,800 元解决了"电机选型 + 减速比 + 刹车 + 承重"四个难题。别自己买轮毂电机搭车架，那是最费钱费时的路。
2. **主控选 x86 迷你主机，不要上 Jetson。** N100 跑 ROS2 顺、装系统不折腾、600 元。真需要 GPU 再补。
3. **能用旧的就用旧的。** 旧平板当屏、旧手机做 4G 热点、旧笔记本做上位机——这三样能再省 500–800 元。

## 二、做什么（开发清单，按这个顺序）

| # | 模块 | 具体做什么 | 工时 | 难点 |
| --- | --- | --- | ---: | --- |
| 1 | 底盘固件 | ESP32 收速度指令 → PWM 驱动/继电器使能；读编码器算里程；急停与看门狗 | 2 周 | 轮椅原控制器是摇杆模拟量，需用 DAC 或双路驱动"骗"它 |
| 2 | 底盘 ROS2 节点 | `/cmd_vel` → 串口协议；发布 `/odom` | 1 周 | 标定轮距与减速比 |
| 3 | 远程链路 | WebRTC 视频 + DataChannel 控制；Cloudflare Tunnel 或 frp 穿透 | 3 周 | **全项目最难**，弱网要自适应码率 |
| 4 | 网页/平板端 | 视频画面 + 虚拟摇杆 + 急停按钮 + 通话 | 2 周 | 移动端触摸手感 |
| 5 | SLAM + 导航 | slam_toolbox 建图，Nav2 点到点 | 2 周 | 家里家具变动要能重定位 |
| 6 | 机械臂运动学 | 4DOF 逆解 + MoveIt 或自写 IK | 2 周 | 4DOF 无腕部姿态，抓取要挑朝向 |
| 7 | 抓取 | 深度相机定位 + 视觉伺服对准 + 夹爪闭合 | 3 周 | 无腕部旋转，需靠底盘转向补偿 |
| 8 | 结构件 | 型材支架、臂底座、屏幕与相机支架 | 2 周 | 3D 打印件要留公差 |

合计约 **17 周**。单人业余（每周 10–15 小时）≈ 6–9 个月。

## 四、家里有老人的四条底线

1. **限速 0.4 m/s**，写死在固件里，网页端改不了。
2. **物理急停**必须串在电机供电上，不经过软件。
3. **机械臂只在有人看着时上电**，无人时断电（继电器控制）。
4. **别在楼梯口、阳台边充电**，画电子围栏，越界直接停。

## 五、这版做不到什么（先说清楚）

| 做不到 | 原因 |
| --- | --- |
| 搀扶老人 | 负载、平衡、责任三重风险，DIY 版绝对不做 |
| 插网线/拧瓶盖 | 千元级臂精度与力控不够 |
| 全自主上门 | 电梯、门禁、异常处理无解 |
| 上街买菜 | 续航、法规、安全都不够 |
| 无人值守运行 | 没有冗余安全设计，必须有人能看见 |

> 这版的定位是"**能替你跑一趟的眼睛和手**"，不是"替你照顾老人的机器人"。把预期放在这里，项目就能做成。
