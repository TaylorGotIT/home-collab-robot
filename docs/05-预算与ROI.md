# 05 · 预算与单台经济模型

> 一句话：**2,495 万元、26 个月，能做出可交付的 B 样与小批。**
> 但真正决定这门生意赚不赚钱的，不是这 2,495 万，而是"一台机器一天能跑几单、一个人能管几台"。

## 五、网络上门安装：ROI 测算

**对标基线**：人工外包 500 元/单（含交通与人工）。

**测算假设（中性情形）**：

| 参数 | 取值 |
| --- | --- |
| 设备单价 | 65,000 元 |
| 折旧年限 / 残值 | 3 年 / 10% |
| 年运维备件 | 5,200 元（设备值 8%） |
| 单机日均单量 | 2.5 单 |
| 年工作天数 | 250 天 |
| 远程工程师配比 | 1 人管 4 台 |
| 远程人力成本 | 18 万元/人/年 |
| 电费 / 流量 / 保险 | 750 / 1,200 / 2,400 元/年 |

**三档结果**：

| 指标 | 保守 | 中性 | 乐观 |
| --- | ---: | ---: | ---: |
| 单机日均单量 | 1.5 | 2.5 | 3.5 |
| 单机年单量 | 375 | 625 | 875 |
| 年固定成本合计 | 91,850 | 74,050 | 55,950 |
| **单次服务成本** | **245 元** | **118 元** | **64 元** |
| 对外报价 | 380 元 | 300 元 | 280 元 |
| 单台年毛利 | 50,625 | 113,750 | 189,000 |
| **设备回本月数** | **17 个月** | **7 个月** | **4 个月** |
| 相对 500 元外包 | 降 51% | **降 76%** | 降 87% |

**单城市模型（可验证，不依赖宏观数据）**：某二线城市宽服商日均 300 单、单均 500 元 → 年支出 5,475 万元。若 30% 标准化订单由机器人完成，年节省约 1,100 万元；即使只替代 10%，也是 550 万元。而 6 台设备投入仅 39 万元。

## 六、敏感性分析：什么才真正影响成本

单次成本 =（年固定成本 + 远程人力 ÷ 配比）÷ 年单量。把两个变量拉开：

| 单次成本（元/单） | 1 人管 3 台 | 1 人管 4 台 | 1 人管 6 台 |
| --- | ---: | ---: | ---: |
| 日均 1.5 单 | 237 | 197 | 157 |
| 日均 2.5 单 | 142 | **118** | 94 |
| 日均 3.5 单 | 102 | 85 | 67 |

**三个结论**：

1. **单量从 1.5 提到 3.5，成本降 57%**；配比从 3 提到 6，成本再降 34%。两者叠加，成本可以从 237 降到 67（3.5 倍差距）。
2. **硬件降价 20%，单次成本只降约 8%**（折旧只占 26%）。所以"等硬件便宜了再做"是错误策略——先跑出单量才是正解。
3. **即使最差组合（237 元）仍低于 500 元外包**，说明这个商业模式的下限是安全的；上不封顶取决于运营。

## 七、家庭场景：一个诚实的结论

家庭场景的情感价值很高，但**在 6.5 万元的成本结构下不赚钱**。

| 项 | 数值 |
| --- | ---: |
| 租赁月费（可接受上限） | 3,200 元/月 |
| 单台月成本（折旧 1,806 + 运维 300 + 接管分摊 500 + 云 94） | 2,450 元/月 |
| 单台月毛利 | 750 元 |
| 回收 6.5 万设备成本 | **87 个月（超过 3 年折旧期）** |

**这解释了为什么必须先做工作场景**：工作场景单机日跑 2.5 单，7 个月回本；家庭场景月费封顶，要 87 个月。用工作场景的现金流养家庭场景的研发，是唯一现实的路径。

**家庭场景成立的三个前提（缺一不可）**：

1. **BOM 降到 2.5 万元以下**（V2）：折旧降至 625 元/月，总成本 1,525 元/月，回本缩短到 **15 个月**。
2. **月费能到 3,200 元以上**：需要"接管服务"成为可感知的卖点（7×24 真人接管），而不是"一个会走的摄像头"。
3. **上门服务导流**：家庭场景的真正利润在后续的维修、代购、陪诊等增值服务，硬件只是入口。

## 八、结论

| 问题 | 答案 |
| --- | --- |
| 要多少钱？ | 2,495 万元，26 个月，建议按 5 个 gate 分批释放 |
| 单台多少钱？ | 原型 10.6 万 / 小批 6.5 万 / 量产 4.1 万 |
| 工作场景赚不赚？ | 赚。中性 118 元/单，报价 300 元，7 个月回本 |
| 家庭场景赚不赚？ | **现在不赚**。要等 BOM 降到 2.5 万，或月费提到 3,200 以上 |
| 最该盯的指标？ | 单机日均单量、一人管几台——不是 BOM |
